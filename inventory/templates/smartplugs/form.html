Como obter os dados (uma vez)

  1. No celular, pareie a tomada no app Smart Life (ou NeoAvant).
  2. Crie conta grátis em iot.tuya.com → Cloud → projeto → Link Tuya App Account (QR no app, aba “Eu”).
  3. No servidor, rode python -m tinytuya wizard e informe API ID/Secret/Região.
  4. Ele gera devices.json com o Device ID e a Local Key de cada tomada.
  5. Pegue o IP na lista de clientes do roteador (e fixe/reserve).

Servidor e tomadas precisam estar na mesma rede. O controle é local — não depende da nuvem.
