Provisionamento KioX

Escaneie este QR no início da configuração de um celular zerado.

Instalação manual (se o Play Protect bloquear)
1. Baixe o APK
Baixar app-release.apk
  1. Instale o adb: 
    sudo apt install android-tools-adb   # Ubuntu/Debian
# Fedora: sudo dnf install android-tools
# Arch:   sudo pacman -S android-tools
  2. Conecte o celular por USB com Depuração USB ligada e toque em Permitir. Confira com adb devices.
  3. Entre na pasta do APK e rode (uma linha por vez): 
    cd ~/Downloads
adb install -r app-release.apk
adb shell dpm set-device-owner com.empresa.semhotspot/.HotspotDeviceAdminReceiver
  1. Instale o adb (platform-tools) no PowerShell: 
    winget install --id Google.PlatformTools -e
    Sem winget? Baixe o "SDK Platform Tools" do Google e extraia. Feche e reabra o terminal após instalar.
  2. Conecte o celular por USB com Depuração USB ligada e toque em Permitir. Confira com adb devices.
  3. Abra o PowerShell na pasta do APK e rode: 
    cd $env:USERPROFILE\Downloads
adb install -r app-release.apk
adb shell dpm set-device-owner com.empresa.semhotspot/.HotspotDeviceAdminReceiver
    Dica: no Explorer, digite powershell na barra de endereço da pasta pra abrir o terminal já nela.

O último comando só funciona com o celular zerado, sem nenhuma conta Google cadastrada.
